Design flow
------------

[Frontend UI]
     |
     v
[FastAPI /documents/upload]
     |
     |-- saves file locally/S3
     |-- inserts document row
     |-- inserts ingestion_jobs row
     |
     v
[Background Task: run_ingestion_job]
     |
     v
[LangGraph: IngestionGraph]
     |
     +--> Node 1: VALIDATION
     |        - update job_status = VALIDATING
     |        - update document_status = PROCESSING
     |
     +--> Node 2: EXTRACTION
     |        - read RawDocument
     |        - extract text from PDF/DOCX/TXT
     |        - update document_status = EXTRACTED
     |
     +--> Node 3: CHUNKING
     |        - split text into chunks
     |        - update job_status = CHUNKING
     |        - update document_status = CHUNKED
     |
     +--> Node 4: EMBEDDING
     |        - create vector embeddings
     |        - update job_status = EMBEDDING
     |        - update document_status = EMBEDDED
     |
     +--> Node 5: VECTOR_INDEX
     |        - save chunks + embeddings
     |        - update job_status = INDEXING
     |        - update document_status = INDEXED
     |
     +--> Node 6: FINALIZATION
              - update job_status = COMPLETED
              - store completed_at
